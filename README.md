One-line out-of-office reply for make.fun's "Funniest One-Line Out-of-Office Reply" bounty: "Out of office: I have left my laptop, my phone, and my will to reply in three separate countries." It reads like a real away message, then the list escalates — the third thing left behind is not a device, it is the will to reply, and the three things are scattered across three separate countries, as if the sender fled in three directions at once.

## Run it

```sh
OUTPUT_DIR=/output python3 main.py
```
